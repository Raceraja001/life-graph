# KNOWLEDGE.md — moved

This file used to be the architecture reference. It was retired on 2026-08-25 because it had
drifted badly: it described 70 endpoints, 13 tables, and 18 events when the codebase actually
had 242 operations, 64 tables, and 77 events. Hand-maintained inventories rot, and a
confidently wrong document is worse than no document.

Its content now lives in two places, split by how fast it changes:

| You want... | Read |
|---|---|
| Why the project exists, the design invariants, the layer model, non-goals, what's still open | **[CHARTER.md](CHARTER.md)** — hand-written, changes rarely |
| The exact current inventory: endpoints, tables, events, personas, tools, jobs, config, migrations, tests | **[docs/STATE.md](docs/STATE.md)** — generated by `scripts/gen_state.py`, cannot drift |
| A browsable version of the same inventory | [docs/feature-inventory.html](docs/feature-inventory.html) |
| Conventions, the build loop, the file map | [AGENTS.md](AGENTS.md) |
| Architecture in depth | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) |

Everything worth keeping — the design decisions, the brain-cycle mapping, the anti-patterns,
and the list of genuine remaining gaps — was folded into `CHARTER.md` before this file was
reduced. Nothing was lost.

To refresh the inventory:

```bash
python scripts/gen_state.py --html   # regenerate docs/STATE.md and the HTML view
python scripts/gen_state.py --check  # exit 1 if docs/STATE.md is stale
```
